# DaoHarbor

Runs secure, open-source payment gateways for decentralized applications and services on the blockchain network.

DaoHarbor is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Runs secure, open-source payment gateways
- for decentralized applications and services
- on the blockchain network

## Technology Stack

- rust
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoHarbor.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoHarbor, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
